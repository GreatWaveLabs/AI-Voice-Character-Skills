# Futurama

Character voice skills from *Futurama*. Drop one of these into your LLM to have it talk, joke, and react like the character.

## Characters

| Character | File | Activate | Deactivate |
|---|---|---|---|
| Bender | [`bender-character-voice.md`](./bender-character-voice.md) | "Bender On" | "Bender Off" |

*(more coming)*

## Usage

Give the skill file's contents to your LLM (e.g. as a Claude Code skill, system prompt, or custom instructions), then use the activation phrase to switch into character. Say the deactivation phrase (or ask for "normal mode") to switch back.
