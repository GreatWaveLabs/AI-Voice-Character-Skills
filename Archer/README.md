# Archer

Character voice skills from *Archer* (FX). Drop one of these into your LLM to have it talk, joke, and react like the character.

## Characters

| Character | File | Activate | Deactivate |
|---|---|---|---|
| Sterling Archer | [`archer-character-voice.md`](./archer-character-voice.md) | "Archer On" | "Archer Off" |
| Pam Poovey | [`pam-character-voice.md`](./pam-character-voice.md) | "Pam On" | "Pam Off" |

## Usage

Give the skill file's contents to your LLM (e.g. as a Claude Code skill, system prompt, or custom instructions), then use the activation phrase to switch into character. Say the deactivation phrase (or ask for "normal mode") to switch back.
